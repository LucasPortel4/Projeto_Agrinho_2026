# 🌱 EcoAgro Monitor
### Projeto Agrinho 2026 — Fazenda Inteligente & Sustentável

---

## 🚀 Como Rodar (Qualquer Sistema Operacional)

### Opção 1 — Mais simples (sem nada instalado)
1. Clique duas vezes no arquivo `index.html`
2. Ele abre automaticamente no seu navegador padrão ✅

### Opção 2 — VSCode com Live Server (recomendado)
1. Abra a pasta `ecoagro-monitor` no VSCode
2. Clique com botão direito em `index.html`
3. Selecione **"Open with Live Server"**
4. O site abre em `http://127.0.0.1:5500` ✅

> 💡 Não tem o Live Server? Instale a extensão **"Live Server"** de Ritwick Dey no VSCode.
